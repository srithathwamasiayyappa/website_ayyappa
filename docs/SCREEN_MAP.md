## Design system

Theme colors and typography are in `src/theme.css`. Raleway is used for headings; Poppins for all content/labels. Desktop navigation displays Home, Categories, Temples, Live, Panchangam, Donations, while mobile has Home, Categories, Profile bottom navigation.

## Interactive static examples

- Choose and persist deity/language.
- Switch login/register tabs and validate mobile input.
- Demo OTP, followed by profile completion and home.
- Update profile/Rashi/Nakshatram (local browser only).
- Search categories and temples, filter by state.
- Change poem and temple profile tabs.
- Switch bhajan/harathi/song lists and bookmark.
- Mark notification list as read.
- Select contribution amount with no payment processing.
- Display external directions links and logout confirmation.
